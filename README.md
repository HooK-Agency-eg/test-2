# موقع Hook

## تشغيل الموقع
1. محتاج Node.js إصدار 18 أو أحدث (nodejs.org).
2. افتح التيرمنال داخل الفولدر واكتب: `node server.js`
3. افتح http://localhost:3000

أول مرة بيتم إنشاء حساب الأدمن بالبيانات دي (ثابتة):
- اليوزر: `mido`
- الإيميل: `mm.Mido1270@gmail.com` (تدخل بيه أو باليوزر)
- الباسورد: `Hook@Mido#1270`

غيّر الباسورد من الداشبورد بعد أول دخول.

لو نسيت الباسورد أو شغلت السيرفر قبل كده: `node server.js --reset-admin` بيرجّعه للباسورد الثابت (أو لـ `ADMIN_PASSWORD` لو محدده).
لو عايز تبدأ من الأول بالنصوص الجديدة، امسح فولدر `data` (بيمسح التعديلات والحسابات).

## الاستضافة
محتاج استضافة تشغّل Node.js (VPS أو Render أو Railway وغيرهم). الاستضافة العادية اللي بتدعم HTML بس هتعرض الموقع بالمحتوى الافتراضي من غير حسابات وداشبورد وتعديل.
- متغيرات اختيارية: `PORT`، `ADMIN_PASSWORD`، `TRUST_PROXY=1` (لو وراء Nginx أو Cloudflare).
- شغّل الموقع على HTTPS.
- كل البيانات في فولدر `data` (قاعدة البيانات db.json) وصور الرفع في `uploads`. خد منهم نسخة احتياطية.

## التعديل
بعد تسجيل دخول الأدمن بيظهر شريط في آخر كل صفحة وأزرار ✎ على المشاريع والعملاء والباقات والأزرار وبيانات التواصل. الداشبورد: `/dashboard.html`

## لو الموقع على GitHub
- GitHub Pages مش بتشغّل Node، يعني الداشبورد والحسابات مش هتشتغل عليه. ارفع المشروع على استضافة Node زي Render أو Railway.
- لو الريبو Public، أي حد يشوف الباسورد الثابت في `server.js`. حط باسورد قوي في متغير `ADMIN_PASSWORD` من إعدادات الاستضافة، وغيّره من الداشبورد.
- فولدر `data` فيه قاعدة البيانات والمفتاح السري، فمتترفعوش على GitHub (ملف `.gitignore` بيمنعهم). لو اترفعوا قبل كده: `git rm -r --cached data uploads` وبعدين commit.

## بدون سيرفر (Google Sheets)
لو الموقع على GitHub Pages، اتبع الخطوات في `apps-script/README.md`.

## ملاحظة عن سيرفر Node
`server.js` نسخة قديمة بتدعم الأساسيات بس (المشاريع والعملاء والباقات والداشبورد). الحسابات المتقدمة والإشعارات والبلاغات ورسايل البريد وحماية الدخول وتعديل نصوص الصفحات شغالة مع Apps Script بس.
